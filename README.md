# MinimalSkills

18 skills for AI coding agents. Markdown only. No build step, no runtime, no tooling.

```
<skill>/SKILL.md            rules, change loop, procedure, tables, checks, report
<skill>/references/*.md     depth, opened only when a routing line sends you there
```

Every edit runs the skill's `## change` loop: locate, propose, predict, back up,
apply, verify, regress, compare, report.
