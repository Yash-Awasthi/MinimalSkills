# Sources

body is preserved verbatim at `references/skills/<skill>.md`, and every non-SKILL.md
file is copied to `references/assets/<skill>/` at the same relative path.

The canonical name drops the `sickn33-expo-` prefix, so `sickn33-expo-api-routes`
becomes `api-routes` and `sickn33-expo-ui-swift-ui` becomes `ui-swift-ui`.
