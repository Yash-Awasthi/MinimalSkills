source body is preserved verbatim at `references/skills/<skill>.md`, and every
non-SKILL.md file is copied to `references/assets/<skill>/` at the same relative path.

The canonical name drops the `sickn33-hugging-face-` prefix, so
`sickn33-hugging-face-jobs` becomes `jobs` and `sickn33-hugging-face-cli` becomes
`hf-cli`.
