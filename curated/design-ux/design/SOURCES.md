# Sources

12 `sickn33-design-*` skill folders became 12 canonical skills in 6 groups. Every
source body is preserved verbatim at `references/skills/<skill>.md`, and every
non-root SKILL.md file is copied to `references/assets/<skill>/` at the same relative
path. The `it` source also carries 48 nested style bodies under `references/assets/it/`.

The canonical name drops the `sickn33-design-` prefix, so
`sickn33-design-taste-frontend` becomes `taste-frontend` and
`sickn33-design-token-contrast` becomes `token-contrast`.
