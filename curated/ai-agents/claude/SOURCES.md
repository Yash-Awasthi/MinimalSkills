# Sources

source body is preserved verbatim at `references/skills/<skill>.md`, and every
non-root SKILL.md file is copied to `references/assets/<skill>/` at the same relative
path.

The canonical name drops the `sickn33-claude-` prefix, so
`sickn33-claude-api` becomes `api` and
`sickn33-claude-win11-speckit-update-skill` becomes `win11-speckit-update-skill`.
